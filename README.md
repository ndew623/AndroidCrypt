### Support ending

The developer of AES Crypt (the encryption library behind AndroidCrypt) is converting the tool into a paid product.

This app will no longer be supported.

You can find the new, official AES Crypt android app on Google Play [here](https://play.google.com/store/apps/details?id=com.terrapane.aescrypt), and the repository is [here](https://github.com/terrapane/aescrypt_android).
This app will support the same file format as AndroidCrypt.
