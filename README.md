### Support ending

The developer of AES Crypt (the encryption library behind AndroidCrypt) is converting the tool into a paid product.

This app will no longer be supported.

You can find the new, official AES Crypt android app [here](https://play.google.com/store/apps/details?id=com.terrapane.aescrypt).
This app will support the same file format as AndroidCrypt.

---

For file encryption tools between desktop and mobile that are free, I recommend looking for tools that support 7zip encrypted archives.

[Fossify File Manager](https://f-droid.org/en/packages/org.fossify.filemanager) is an open source file manager on Fdroid that supports creating and opening encrypted 7zip archives.

[ZArchiver](https://play.google.com/store/apps/details?id=ru.zdevs.zarchiver) is a free app on the Google Play Store that also has support for encrypted 7zip archives.

Warning: These free apps use common file compression formats. They are not compatible with the AES Crypt format that AndroidCrypt uses.
